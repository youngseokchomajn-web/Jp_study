# 2026-10-12 최근 논문 비교 — 도쿄대·도요하시·규슈대

## 목적

영어 석사 경로가 확인된 후보 중에서, 사용자의 약 4년 CAE/시뮬레이션·공작기계 구조진동 경험을 살리면서 석사 연구로 확장할 수 있는 실질적 연구문제를 찾는다. 논문 제목이나 키워드만 나열하지 않고, 연구문제·방법·검증·적용 가능성을 분리한다.

## 1. 도쿄대 IME — Sugita / Kizaki 연구그룹

공식 IME 참여 명단에는 Naohiko Sugita, Toru Kizaki, Hayato Yoshioka가 기계공학 분야 후보로 기재되어 있다. 이번 비교에서 확인된 최근 논문은 Sugita/Kizaki 그룹과 연결된다.

### 논문 A — reduced-order model 기반 센서 위치 최적화
- Yuta Teshima, Shun Tanaka, Toru Kizaki, Naohiko Sugita (2024), “Sensor placement strategy based on reduced-order models for thermal error estimation in machine tools,” *CIRP Journal of Manufacturing Science and Technology* 55, 403–410.
- DOI: https://doi.org/10.1016/j.cirpj.2024.10.015
- 원문/초록: https://www.sciencedirect.com/science/article/pii/S175558172400169X

**연구 문제:** 공작기계 열오차를 추정할 때 센서를 어디에 몇 개 놓아야 하는가? 센서를 실제로 부착하기 전에 모델을 사용해 위치와 개수를 최적화할 수 있는가?

**방법:** 모델 차수 축소(ROM), 전달함수 행렬, 민감도 함수를 이용해 센서 수와 위치를 최적화했다.

**검증:** 3축 머시닝센터에서 실험 검증. 센서 수를 50% 줄이고 노트북에서 즉시 계산할 수 있음을 보고했다.

**사용자와의 연결:** 이미 가진 CAE/시뮬레이션 경험을 ROM·민감도 분석·계측 설계로 확장할 수 있다. 스핀들/구조진동에서 다수의 FRF·센서 조합을 줄이는 문제와 방법론적으로 닮았지만, 이 논문 자체는 진동보다 열오차에 초점이 있으므로 동일한 연구라고 과장하지 않는다.

### 논문 B — 기계 구조의 온도 민감 지점 분석과 희소 모델링
- Shun Tanaka, Toru Kizaki, Yuta Teshima, Naohiko Sugita (2025), “Comprehensive Analysis of Temperature-Sensitive Points Across Machine Tool Structures Using Highly Redundant Temperature Data and Sparse Modeling,” *International Journal of Automation Technology* 19(5), 758–773.
- DOI: https://doi.org/10.20965/ijat.2025.p0758
- J-STAGE 원문: https://www.jstage.jst.go.jp/article/ijat/19/5/19_758/_article/-char/en

**연구 문제:** 공작기계 구조 곳곳의 다량 온도 데이터에서 유효한 센서 위치를 어떻게 골라내는가?

**방법:** 307개 지점의 온도 데이터를 6개 운전 패턴에서 수집하고, 상관 분석과 LASSO 희소 회귀로 센서 수와 위치를 줄였다.

**검증/결과:** 3축 수평 머시닝센터 데이터에서 센서 수를 76% 줄이면서 RMSE를 10 µm 미만으로 유지했다고 보고한다.

**사용자와의 연결:** 센서·자유도·운전 자세가 많은 CAE 모델에서 대표 계측점 또는 대표 응답을 선별하는 문제에 방법론적으로 연결할 수 있다. 다만 열오차 예측과 진동 FRF 검증은 물리량과 검증 기준이 다르므로, 연구계획에서는 방법론 전이로 설명해야 한다.

### 논문 C — 공작기계 동역학의 모드형상 데이터베이스 기반 추정
- Jiahui Liu, Toru Kizaki, Zongwei Ren, Naohiko Sugita (2022), “Mode shape database-based estimation for machine tool dynamics,” *International Journal of Mechanical Sciences* 236, 107739.
- DOI: https://doi.org/10.1016/j.ijmecsci.2022.107739
- 논문: https://www.sciencedirect.com/science/article/pii/S0020740322006191

**연구 문제:** 절삭 위치가 변하면서 공작기계 전체의 모드형상이 바뀔 때, 운전 중 동역학을 어떻게 추정할 수 있는가?

**방법:** 절삭 위치 변화에 따른 모드형상을 데이터베이스로 구축하고, 모드형상 매칭과 transmissibility 보정을 통해 시스템 동역학을 추정한다.

**검증:** 공작기계 FEM 모델을 사용해 제안법을 검증했으며, 시뮬레이션에서 고유진동수 추정 최대 오차가 0.04% 이내라고 보고했다. 실기 운전 중 적용은 향후 가능성으로 제시되어 있어 실기 완성도를 과대평가하지 않는다.

**사용자와의 연결:** 현재까지 확인된 후보 중 CAE/공작기계 구조동역학 경험과 가장 직접적으로 연결되는 연구다. 다만 사용자가 수행했던 모델과 이 논문의 모델·데이터가 같다고 가정하지 않는다.

### 도쿄대 임시 해석
세 논문은 공작기계 모델, 센서/모드 데이터의 축약, 동역학·오차 추정, 시뮬레이션과 실험 검증이라는 연결점을 공유한다. 사용자의 배경을 유지하면서 모델 축약·계측 설계·상태 추정으로 확장하기 좋은 후보이다. 다음에는 Yoshioka 연구진의 최근 논문과 Kizaki/Sugita의 지도 가능성을 별도로 확인한다.

## 2. 도요하시기술과학대 — Kawamura / Tajiri, Machine Dynamics Laboratory

### 논문 A — 신경망 기반 비선형 시스템 파라미터 식별
- Daiki Tajiri, Kosuke Nakajima, Masaki Ikeda, Shozo Kawamura, Masami Matsubara, “Proposal of a parameter identification method for single-degree-of-freedom nonlinear systems using neural networks,” *Mechanical Engineering Journal*.
- DOI: https://doi.org/10.1299/mej.24-00292
- J-STAGE: https://www.jstage.jst.go.jp/article/mej/advpub/0/advpub_24-00292/_article/-char/en

**연구 문제:** 비선형 진동계에서 질량·감쇠·강성 등 선형 파라미터와 비선형 복원력을 어떻게 분리해 식별할 수 있는가?

**방법:** 운동방정식의 힘 평형을 이용해 선형 파라미터를 추출하는 로컬 신경망과 비선형 복원력을 표현하는 글로벌 신경망을 결합한다. 가진력, 가속도, 속도, 변위를 입력으로 활용한다.

**검증:** Duffing, Van der Pol 및 사인 형태 복원력을 갖는 시스템의 수치 시뮬레이션 데이터를 이용해 방법의 유효성을 확인했다. 확인한 자료 범위에서는 실제 기계 장치에서의 실험 검증을 완료했다고 단정할 수 없다.

**사용자와의 연결:** 물리 기반 운동방정식과 데이터 기반 보정을 결합하는 방향과 직접 연결된다. 다만 단자유도 모델의 방법을 다자유도 스핀들 시스템에 바로 적용할 수 있다고 가정해서는 안 되며, 식별 가능성·노이즈·모델 불일치 검증이 필요하다.

### 논문 B — 추가 진동 시스템을 이용한 층상 구조물 이상 진단
- Daiki Tajiri, Shozo Kawamura, Kaito Araki (2025), “Simple abnormality diagnosis of layered structures using an additional vibratory system,” *Mechanical Engineering Journal* 12(2), 24-00475.
- DOI: https://doi.org/10.1299/mej.24-00475
- J-STAGE: https://www.jstage.jst.go.jp/article/mej/12/2/12_24-00475/_article/-char/en

**연구 문제:** 추가 진동 시스템의 응답을 이용해 층상 구조물의 이상 위치·정도를 식별할 수 있는가?

**방법/검증:** 추가 진동 시스템의 FRF를 활용하는 이상 진단법을 제안하고 수치 시뮬레이션 및 실험 모델로 검증했다.

**사용자와의 연결:** 구조동역학·FRF·이상 진단과 직접 관련이 있다. 다만 응용 대상은 건축 구조물이며, 공작기계 스핀들 적용은 별도 연구 질문으로 재구성해야 한다.

### 논문 C — 신경망을 이용한 층상 구조 진단
- Daiki Tajiri, Tatsuru Hioki, Shozo Kawamura, Masami Matsubara (2024), “Simple diagnosis for layered structure using convolutional neural networks,” *Archive of Applied Mechanics* 94, 3135–3155.
- DOI: https://doi.org/10.1007/s00419-024-02661-y

**연구 문제:** 구조 응답을 기반으로 이상 상태를 구분할 때 CNN을 활용할 수 있는가?

**검증 상태:** 논문 초록과 서지 정보를 확인했다. 모델 입력, 데이터 분할, 외부 검증, 오탐/미탐 지표는 본문을 추가로 읽어야 하므로 이번 단계에서는 미확인으로 남긴다.

### 도요하시 임시 해석
도요하시는 진동 시스템의 파라미터 식별·FRF·이상 진단이라는 방법론과 강하게 맞는다. 특히 물리 기반 모델과 신경망을 결합하는 연구는 사용자의 확장 방향 A와 관련성이 높다. 다만 실제 기계 장치 검증과 데이터 접근성을 교수에게 확인해야 한다.

## 3. 규슈대 — Inoue / Mori, Machinery Dynamics Laboratory

### 논문 — 2자유도 플랫폼에 장착된 두 회전체의 자기동기 현상
- Hiroki Mori, Miwa Sueda, Naruki Kuboyama, Nobuyuki Sowa, Takumi Inoue (2025), “Energy-based analysis and experiment for self-synchronization of two rotors installed in two-DOF translational system,” *Mechanical Systems and Signal Processing* 234, 112778.
- DOI: https://doi.org/10.1016/j.ymssp.2025.112778
- 공식 연구자 포털: https://kyushu-u.elsevierpure.com/en/publications/energy-based-analysis-and-experiment-for-self-synchronization-of-/

**연구 문제:** 2자유도 플랫폼에 설치된 두 불평형 회전체의 자기동기 조건이 플랫폼의 진동 이방성과 회전체 회전 방향에 따라 어떻게 달라지는가?

**방법:** 에너지 기반 조건식과 근사 해석을 구성해 동기화 가능한 파라미터 영역을 예측한다.

**검증:** 분석 모델을 수치해석 결과와 실험 장치 결과 모두에 비교해 검증했다.

**사용자와의 연결:** 회전체·진동 시스템의 물리 모델, 파라미터 영향 분석, 실험 검증이라는 기반이 있다. 다만 공작기계 스핀들·절삭 동역학과 직접 같은 문제는 아니므로, 회전체 동역학의 방법론적 확장 후보로 평가한다.

|---|---|---|---|---|---|
| 도쿄대 Sugita/Kizaki | 공작기계·스핀들·모드/열오차와 직접 연결 | 강함 | ROM, LASSO, 데이터베이스 기반 추정 | 논문별로 실험/시뮬레이션 확인 | 기존 경력 연속성이 가장 높음 |

이 표는 연구 적합성 비교이며, 영어 석사 지원 가능성이나 합격 가능성 순위가 아니다. 프로그램-연구실 연결은 앞선 로그의 별도 상태를 유지한다.

## 5. 연구 주제 후보의 현재 수렴 방향

현재 확인된 논문을 바탕으로 다음과 같은 연구 질문이 유망하다.

**임시 연구 질문:** “운전 조건과 자세가 바뀌는 기계 시스템에서, 물리 기반 FEM/동역학 모델과 제한된 계측 데이터를 이용해 동특성 변화를 효율적으로 추정하고, 검증에 필요한 대표 센서·모드·FRF를 선택할 수 있는가?”

- 적용 시스템: 공작기계 또는 스핀들 시스템 중 하나로 좁힌다.
- 방법: 모델 축약/모드형상 데이터베이스/파라미터 식별 중 핵심 방법 하나를 선택한다.
- 측정 가능한 출력: 고유진동수·FRF 추정 오차, 필요한 센서/계측점 비율, 계산시간, 운전조건 변화에 대한 일반화 성능.
- 검증: FEM 기반 검증과 실제 실험 데이터 검증을 구분한다. 실험 데이터 접근 가능성이 확인되지 않으면 실험을 전제로 연구계획을 확정하지 않는다.

이 질문은 확정 주제가 아니라 후보 연구실과 데이터를 확인하기 위한 작업 가설이다.

## 6. 다음 작업
1. 도쿄대 Yoshioka의 최근 논문을 조사하고, Sugita/Kizaki와의 세부 연구 차이를 정리한다.
2. 도요하시 논문에서 실제 실험 데이터·공개 데이터·연구실 내 장비 사용 가능성을 확인한다.
3. 규슈대 후보의 2022–2026 논문을 더 모아 비선형 회전체 외에 FRF/상태진단의 비중을 확인한다.
4. Science Tokyo 및 Tohoku IMAC-G에서 비슷한 연구 질문을 수행하는 실제 참여 교수 후보를 찾아 프로그램 소속과 함께 기록한다.
5. 비용은 계속 별도 조사하되 연구실 점수나 후보 순위에 넣지 않는다.
