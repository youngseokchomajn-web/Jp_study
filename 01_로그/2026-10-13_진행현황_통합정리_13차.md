## 2. 프로젝트 기준선

- 대상은 일본 전국 18개 대학이며, 학교별 순차 완료가 아니라 전 학교를 동일 기준으로 병렬 조사한다.
- 지원자 기준: 기계공학 계열, GPA 약 3.5–3.99/4.5, 기계·공작기계·스핀들/베어링·구조진동 관련 CAE/시뮬레이션 실무 약 4년.
- 연구 관심: 물리 기반 모델과 데이터 기반 보정, 파라미터 식별·차수축소 모델, 공작기계 동역학·정밀기계, 로봇 동역학·제어, 진동 기반 상태감시·고장 예측.
- 일본어 초급 이하이며, 영어로 정규 독립 석사학위를 완료할 수 있는 경로는 필수 조건이다.
- OPIc 보유는 TOEFL/IELTS 대체 인정의 증거가 아니다. 공식 전형요강이 명시하지 않으면 대체 불가로 취급한다.
- 도쿄권 선호는 유지하되 연구 적합성이 높으면 전국 후보를 유지한다.
- 비용은 조사·기록하되 대학 제외나 후보 순위의 판단 기준으로 사용하지 않는다.
- 2027년 지원 가능 경로는 선별 검토하고, 2028년 대안을 병행한다. 공고 전 일정을 확정 일정으로 만들지 않는다.
- 합격 확률을 근거 없이 숫자로 만들지 않는다.

## 7. 네 가지 평가축과 논문 근거 수준

### A — 영어 독립 석사 경로
정규 독립 석사인지, 학위명, 강의 언어, 연구지도 언어, 논문 언어, 해당 전공의 프로그램 참여, 지원 자격을 각각 확인한다.

### B — 실제 연구실 연결
공식 연구실·교수 정보, 영어 프로그램 참여, 지도 언어, 해당 입학 회차 신규 석사생 수용 가능 여부, 교수 사전 동의 조건을 확인한다. 자료 부족은 OPEN으로 둔다.

### C — 논문 근거
2022–2026년 연구를 우선하되 핵심 기반 논문은 이전 연도도 허용한다. 제목·초록·본문을 실제로 확인한 범위를 구분한다.
- E1: 서지정보 확인
- E2: 공식 초록 확인
- E3: 본문 방법·데이터·검증 확인
- E4: 한계·재현성·외부 검증까지 확인

### D — 지원 실행성
2027년 실제 지원 가능 회차와 2028년 대안, TOEFL/IELTS/GRE, 추천서, 연구계획서, 사전 컨택, 온라인 신청, 서류 도착, 시험·면접을 단계별로 기록한다.

A/B/C/D를 하나의 합산 점수로 만들지 않는다. 영어 학위 경로가 미확인인 후보는 연구 적합성이 높더라도 확정 후보로 승격하지 않는다.
