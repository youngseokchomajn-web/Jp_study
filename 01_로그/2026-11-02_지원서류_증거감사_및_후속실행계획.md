# 2026-11-02 지원서류 증거 감사 및 후속 실행계획

## 목적
21~22차 산출물의 제출 가능성을 재검토하고, 사실로 확인되지 않은 지원자 이력과 성과를 제거한다. 조사 원본과 과거 초안은 보존하되, 지원에 사용할 문서는 별도 수정본으로 관리한다.

## 확인한 문제
기존 CV·포트폴리오·교수 이메일에 GPA/WES 환산, 직급, 구체적 회전속도, 오차율, 개선율, EMA 및 계측 수행, TMD, 장비·소프트웨어, 수상·자격·논문 등이 검증 자료 없이 기재되어 있었다. 이 항목들은 사용자 확인 또는 증빙 전까지 제출용 사실로 사용할 수 없다.

입시 계획에도 TOEFL 점수 목표를 실질 합격선처럼 표현하거나, 2028 모집 일정·추천서·재정증명·교수 사전 내락을 공통 조건처럼 단정할 위험이 있었다. 학교별 공식 모집요강이 공개되기 전까지 미확인 상태로 유지한다.

## 수정 원칙
1. 사용자가 실제로 설명한 업무 범위(공작기계 구조·진동 CAE, 스핀들·베어링계, 하우징/헤드 구조 FRF 영향, 베어링 강성·예압·접촉각 관련 관심·업무)를 중심으로 기술한다.
2. 정확한 학교·학위·GPA·재직기간·직급·툴·프로젝트 수치 등은 증빙 또는 본인 확인 전까지 빈칸으로 둔다.
3. 실험 모달 시험, EMA, TMD, 채터 개선, 구체적인 수치 성과를 수행 사실로 쓰지 않는다.
4. 연구계획서는 확정된 실적이 아니라 석사과정에서 검증할 연구 질문과 조건부 방법으로 작성한다.
5. 교수 이메일은 최근 논문과 공식 프로그램을 확인한 뒤 개별화한다.
6. FRF 허수부를 감쇠량과 동일시하지 않는다. 반전력 대역폭법의 적용 가정과 한계를 설명한다.
7. 2028년 입시 일정은 공식 발표 전 확정값으로 쓰지 않는다. TOEFL 학습계획은 사용자 개인 관리 범위이며 이 저장소는 학교별 공식 요건만 기록한다.

## 이번 수정 파일
- Academic CV — evidence-controlled draft
- Technical CAE Portfolio — working draft and evidence register
- Research Proposal — research question, work packages and scope controls
- Professor Outreach Email Pack — factual templates and send checklist
- 2028 admissions master plan and execution roadmap
- Oral / technical interview guide
- README / links to be reconciled after the content review

## 사용자 확인이 필요한 핵심 자료
- [ ] 공식 성적증명서의 GPA, 대학명, 학위명, 졸업일
- [ ] 회사명 공개 가능 여부, 공식 직급, 정확한 입사일
- [ ] 실제 사용한 CAE 솔버/전처리/후처리/코딩 도구
- [ ] 개인이 직접 수행한 프로젝트 2건과 각 기여 범위
- [ ] 실험/계측을 직접 수행한 경험이 있는지, 있다면 장비·역할·자료
- [ ] 외부 공개 가능한 익명화 그림·결과·보고서
- [ ] 공식 영어 성적, 자격·수상·논문 여부
- [ ] 추천인 후보 및 추천 의사 동의

## 다음 실행 순서
1. 사용자가 위 확인 자료를 제공하거나 확인한다.
2. CV를 먼저 확정하고 모든 사실 문장을 evidence register에 연결한다.
3. 실제 프로젝트 2건을 포트폴리오 case study로 작성한다.
4. 연구계획서를 목표 연구실의 최근 논문과 시설에 맞춰 변형한다.
5. 후보 대학별 공식 모집요강을 확보하고 상태값을 갱신한다.
6. 교수 컨택 정책과 학생 수용 여부를 확인한 뒤 맞춤 이메일을 발송한다.
7. 학교별 실제 시험 형식에 맞춰 구술 준비 범위를 확정한다.
8. 최종 제출본에 대해 링크, 숫자, 인용, 기밀성, 파일명, 문서 간 정합성 검사를 수행한다.

## 검수 상태
이번 커밋은 문서의 위험한 주장을 보수적으로 정리한 초안 수정이다. 사용자 증빙을 확인한 최종 제출본은 아니다. 원본 조사자료는 보존하며, 수정본의 빈칸을 임의로 채우지 않는다.
