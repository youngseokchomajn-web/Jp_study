# 연구주제 확장성 비교표

상태: 1차 비교 / 최종 선택 전

| 연구축 | 핵심 방법 | 기존 CAE 활용 | 다른 분야로의 확장 예시 | 주요 학습 부담 | 가장 중요한 확인 사항 |
|---|---|---|---|---|---|
| 물리 모델 + 데이터 기반 학습 | 물리 모델, 데이터 보정, 모델 축소·예측 | 높음 | 제조, 로봇, 에너지, 자동차, 구조물 감시 | 통계·ML·프로그래밍 | 데이터와 검증 기준을 갖춘 구체적 연구 질문 |
| 로봇 동역학·제어 | 동역학 모델, 시뮬레이션, 제어·최적화 | 중~높음 | 로봇, 자동화, 정밀 조립, 모션 시스템 | 기구학·제어이론·프로그래밍 | 실제 석사 프로젝트와 수학적 선행 지식 |
| 진동 기반 상태진단 | 진동·신호 분석, 이상 탐지, 수명 예측 | 높음 | 제조, 철도, 자동차, 에너지·설비 신뢰성 | 신호처리·ML·데이터 품질 | 고장 데이터의 대표성 및 외부 검증 |
| 정밀기계·공작기계 동역학 | 구조·회전계 모델링, FRF, 이송계·정밀도 | 매우 높음 | 공작기계, 정밀장비, 제조 R&D, 모션 제어 | 실험 검증·모델 업데이트 | 선행연구와 차별성, 장비·데이터 접근 |

## 해석
- '확장 가능성'은 가능한 적용 영역의 예시이지 취업 보장이 아니다.
- 기존 CAE를 활용하는 정도와 분야 전환 가능성은 서로 다른 축으로 평가한다.
- 연구실의 교수·논문·장비가 실제로 해당 주제를 뒷받침하는지 별도로 검증한다.
- 대학의 영어 과정, 교수의 영어 지도, 입학 영어시험 인정, 사용자의 지원 자격을 각각 따로 확인한다.
