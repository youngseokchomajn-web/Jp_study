# Jp_study — 일본 대학원 진학 조사 기록

일본 석사 진학 후보, 지도교수, 영어 수업·입학 요건, 기업 공동연구 가능성을 조사하고 판단 근거를 보존하는 프로젝트입니다.

## 핵심 목표
- 도쿄 및 도쿄 근교를 우선으로 보되, 연구 적합성이 높으면 일본 전국의 기계공학·CAE/시뮬레이션·공작기계·로봇/제어 연구실을 검토한다.
- DMG MORI, 야마자키 마작, 오쿠마 등 공작기계 기업과의 실제 연구 접점을 확인한다.
- 영어로 학위를 취득할 수 있는지와 실제 입학 요건을 별도로 검증한다.
- 결론뿐 아니라 당시의 근거, 대안, 미확인 사항, 판단 보류 이유를 남긴다.
- 나중에 판단을 다시 열 때 이전 판단을 지우지 않고 새 근거와 변경 사유를 연결한다.

## 사용자 기준선
- 기계공학 CAE/시뮬레이션 실무 경력: 약 4년
- 학부 GPA: 약 3.5–3.99 / 4.5
- 관심 우선순위: ① 공작기계 + CAE + 로봇/제어 ② 공작기계 + CAE. 기존 경험을 활용하면서 확장 가능한 연구 주제도 비교
- 영어: OPIc 보유, TOEFL 준비 예정. TOEFL 목표 점수는 후보 대학의 실제 전형 요건을 비교한 뒤 정한다.
- 일본어: 초급 이하
- 지역: 도쿄권 우선 선호는 유지하되, 연구 적합성이 높은 전국 대학도 비교
- 비용: 학비·입학금·생활비·장학금을 조사해 기록하되, 대학 제외 및 후보 순위의 판단 기준으로 사용하지 않음 (기존 연간 예산 150만~250만 엔은 참고 정보로만 보관)
- 입학: 2027년 지원 가능한 곳은 선별 검토, 2028년 입학 준비 병행
- 졸업 후 한국 복귀 선호

프로필은 새 정보가 확인되면 갱신한다. 이 정보만으로 합격 확률을 숫자로 단정하지 않는다.

## 운영 규칙
1. 새 조사 전 README, 미결 목록, 관련 대학·판단 기록을 먼저 읽는다.
2. 공식 모집요강, 대학·연구실·기업의 1차 자료를 우선한다.
3. 영어로 정규 석사학위를 마칠 수 있는 경로를 첫 번째 필수조건으로 검증한다. 대학의 영어 학위과정, 교수의 영어 지도, 해당 연구실의 프로그램 참여 및 석사생 모집, 지원 자격은 각각 별도 확인한다.
4. 비용은 조사·기록하되, 대학 제외나 후보 순위 산정에 반영하지 않는다.
5. 사실·추정·미확인을 구분한다.
6. 결론을 미뤄도 미결 목록에 이유, 필요한 증거, 재검토 조건을 남긴다.
7. 중요한 판단은 별도 DEC 문서로 기록한다. 판단 변경 시 기존 기록을 삭제하지 않는다.
8. 조사 날짜, 출처 URL, 페이지·표·항목, 확인 상태를 기록한다.
9. 매 세션 끝에 확인 사실, 바뀐 판단, 미결 사항, 다음 행동을 로그로 남긴다.

## 상태 표기
- CONFIRMED: 공식 자료로 확인
- SUPPORTED: 신뢰할 만한 근거가 있으나 추가 확인 필요
- HYPOTHESIS: 합리적 추정, 사실로 인용 금지
- OPEN: 판단 보류
- REJECTED: 기준에 맞지 않아 제외
- SUPERSEDED: 후속 판단으로 대체됨

Gemini 원본 보고서와 CSV는 조사 산출물로 보존한다. 파일 생성·표 수록만으로 사실 검증이 완료된 것은 아니다. TOEFL/GRE 점수 목표, 장학금 수혜율, 대학-기업 연계, 연구실의 실제 석사생 수용 여부는 공식 근거를 별도로 확인하기 전까지 확정 사실로 사용하지 않는다. 최신 감사 기록: [17차 증거 감사](01_로그/2026-10-13_Gemini_산출물_증거감사_17차.md).

## 현재 작업 기준 — 증거 감사 후속
현재 논문 근거 CSV에는 DOI/제목 불일치와 전문에서 확인되지 않은 정량 주장이 발견됐다. 원본 CSV는 보존하고, 검증이 끝나기 전까지 기존 E3/E4 표기를 사실로 인용하지 않는다. 다음 Gemini 실행은 18개 대학 조사를 처음부터 반복하는 것이 아니라, DOI/서지 확인 → 주장 단위 원문 검증 → 영어 석사 프로그램과 연구실 연결 검증 → 별도 검증본 생성 순서로 진행한다.

### 현재 핵심 운영 규칙 및 검증 기준
1. **University of Tokyo / UTokyo 영구 배제**: 활성 후보 및 신규 조사 대상에서 전면 제외하며 과거 기록은 역사 자료로만 보존한다.
2. **Science Tokyo (구 도쿄공대) 독립 조사**: 별도 대학으로 적극 포함하되, 2028년 4월 입학은 과거 패턴(`HISTORICAL_PATTERN`)으로 분류하고 공식 요강 미공고 상태를 엄격히 구분한다. Nakano 교수 연구실 수용 여부(`OPEN`)와 연구 적합도(E3)를 상호 분리한다.
3. **도호쿠대(Tohoku IMAC-G) 판정 보류**: 현재 구체적 공지는 2027년 10월 입학 기준만 존재하므로 2028년 4월 입학을 `UNKNOWN`으로 판정하고 공식 요강 확인 전까지 핵심 후보에서 보류(`ON_HOLD`)한다.
4. **2028년 4월 입시 상태 5대 표준 카테고리 엄격 준수**:
   - `CONFIRMED`: 2028년 공식 모집요강 공개
   - `HISTORICAL_PATTERN`: 과거 연도에 동일한 입학 시기 운영
   - `CONDITIONAL`: 프로그램 또는 연구실 확인 필요
   - `UNKNOWN`: 근거 부족 / 미확인
   - `NOT_AVAILABLE`: 해당 과정에서 해당 입학 시기 미운영 확인
5. **연구 적합도와 석사생 수용 여부 분리**: TUAT Yamato 연구실 등 연구 적합성이 아무리 높아도 영어 석사 연결, 4월 입학, 석사생 실제 수용 여부는 각각 분리하여 별도 확인(`CONDITIONAL_TOP_FIT`)한다.
6. **전형 안정성 높은 주력 지원군 확립**: 규슈대(Kyushu), 히로시마대(Hiroshima), 홋카이도대(Hokkaido)를 실행 가능성 높은 주력 풀로 병행 준비한다.
7. **CSV 데이터 무결성 원칙**: RFC 4180 표준을 준수하여 쉼표 포함 필드의 따옴표 이스케이프를 유지하고 19개 대학의 모든 행/열 정합성을 검증한다.
