# DEC-004 — 핵심 논문 검토 후 연구주제 임시 우선순위

- 날짜: 2026-10-12
- 상태: PROVISIONAL
- 관련 결정: DEC-003
- 근거 로그: [2026-10-12 핵심 논문·연구주제·입시 리스크 검토](../01_로그/2026-10-12_핵심논문_연구주제_입시리스크_검토.md)

## 임시 결정

우선 조사할 주제는 **물리 기반 동역학 모델 + 데이터 기반 보정/학습**으로 둔다. 첫 적용 시스템은 사용자의 경험과 직접 연결되는 스핀들-베어링 계를 기준으로 하되, 최종 연구 주제를 확정하지 않는다.

## 결정 근거

1. 공작기계 동역학 측정 논문은 모델 예측과 실험 측정을 결합해 FRF 및 안정성 예측을 검증하는 구체적인 연구 설계를 보여준다.
2. 스핀들 상태진단 논문 시리즈는 물리 기반 결함 모델, 동적 시뮬레이션, 실험 검증, 데이터 기반 진단을 하나의 흐름으로 연결한다.
3. Physics-enhanced ML 리뷰는 방법론의 선택지가 다양하다는 점을 보여준다. 따라서 특정 AI 기법을 먼저 정하기보다 데이터 조건과 연구 질문에 맞춰 선택해야 한다.
4. 로봇의 위치·기하 오차 측정/보정은 공작기계 정밀도 연구와 방법론적 접점이 있어 대안으로 유지할 가치가 있다.

## 석사 범위의 가드레일

- 핵심 방법 하나, 적용 시스템 하나, 평가 출력 1~2개로 한정한다.
- 우선 출력은 FRF/공진 주파수/동적 강성 예측 오차 중 1~2개를 고려한다.
- 측정 데이터, 공개 데이터, 연구실 보유 데이터 중 현실적으로 접근 가능한 검증 자료가 확인되지 않으면 주제를 재설계한다.
- 실제 고장진단을 선택할 경우 고장 데이터와 독립 검증 조건을 반드시 확인한다.
- “확장성이 높다”는 이유만으로 PINN이나 딥러닝을 무리하게 도입하지 않는다.

## 보류한 대안

- 로봇 동역학·제어: 로봇 오차 측정/보정과 동역학 제어를 구분해 연구실별 적합성을 추가 확인한다.
- 공작기계 동역학/CAE: 기존 경험을 가장 직접적으로 활용하는 기준선으로 유지한다.
- 진동 기반 상태진단: 데이터와 외부 검증 접근성이 확인될 경우 물리 모델 기반 접근과 결합한다.

## 입학 경로에 대한 별도 판단

- 2027년 NITech 외국인 사비유학생 모집요강은 TOEFL iBT 또는 TOEIC L&R 성적 제출을 명시한다. OPIc만으로 충족한다고 볼 수 없다.
- Hiroshima University는 일부 석사 전형에서 TOEFL/TOEIC/IELTS 등 정해진 영어시험 점수를 요구한다. 적용 대상 전형이 다르므로 2028년 모집요강에서 재확인해야 한다.
- 연구실의 주제 적합성과 지원 자격/영어시험/영어 지도 가능 여부는 서로 다른 검증 항목이다.

## 재검토 조건

아래 중 하나라도 해당하면 주제 우선순위를 재검토한다.
1. 목표 연구실에 측정 데이터·실험장비 접근성이 없다.
2. 지도교수가 해당 연구 질문을 석사 주제로 지도할 의향이 없다.
3. 데이터 기반 보정의 연구 기여가 기존 논문과 충분히 구분되지 않는다.
4. 필요한 코딩·제어·수학 선행지식을 2년 내 보완하기 어렵다.
5. 영어 전형 또는 일정이 현실적으로 맞지 않는다.

- 2028년 전형 자료가 공개되면 영어시험 인정 여부와 일정은 새 증거로 갱신한다.
