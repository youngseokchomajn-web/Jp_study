# DEC-003 — 연구 확장성 우선 비교 원칙

- 날짜: 2026-10-12
- 상태: PROVISIONAL
- 대체 대상: DEC-002의 단일 중심축 가정은 유지하지 않고, 후보를 병렬 비교하도록 확장한다.

## 결정 질문
한국 복귀 후 전문성 강화 또는 이직을 목표로 할 때, 기존 CAE 경력을 활용하면서도 다른 산업·직무로 확장할 수 있는 석사 연구주제를 어떻게 비교할 것인가?

## 사용자 선호
- 기존 경험과 직접 관련된 연구만을 선택 조건으로 삼지 않는다.
- 분야 전환 가능성을 중요하게 본다.
- 연구 스타일은 미정이며 여러 분야를 비교한 후 결정한다.
- 졸업 후 한국 복귀를 기본 시나리오로 둔다.

## 평가 기준
1. 기술의 전이 가능성: 다른 산업에서도 활용할 수 있는 방법론인가?
2. 기존 경험의 활용: 구조진동·스핀들·베어링 CAE 경험이 출발점이 될 수 있는가?
3. 석사 범위의 실현 가능성: 2년 안에 연구 질문과 검증을 마칠 수 있는가?
4. 연구실 적합성: 최근 논문·장비·데이터·교수의 실제 지도 범위가 맞는가?
5. 입학 경로: 정규 석사과정, 영어 요건, 지원 자격을 공식 문서로 확인할 수 있는가?
6. 한국 복귀 후 설명 가능성: 어떤 기술을 습득했고 어떤 직무에 적용할 수 있는지 명확한가?

## 잠정 순위 — 조사 우선순위이지 최종 추천 순위가 아님
1. 물리 기반 모델 + 데이터 기반 학습: CAE에서 출발해 다양한 물리 시스템으로 확장할 가능성.
2. 로봇 동역학·제어: 기계시스템 모델링 경험을 로봇·자동화로 확장할 가능성.
3. 진동 기반 상태진단·고장 예측: 동역학·신호 데이터와 신뢰성·예지보전의 연결.
4. CAE 기반 정밀기계·공작기계 동역학: 기존 전문성을 강화하는 기준점이며, 데이터·제어 방법을 결합할 수 있는지 확인.

## 반대 근거 및 위험
- 확장성이 높은 주제는 수학·코딩·데이터 처리의 학습 부담이 클 수 있다.
- 넓은 키워드를 한 프로젝트에 모두 넣으면 석사 연구가 완성되지 않을 수 있다.
- 특정 분야의 인기가 개인의 적성이나 취업 성과를 보장하지 않는다.
- 교수의 연구 분야가 넓다고 해서 석사생에게 해당 주제를 지도할 수 있다는 뜻은 아니다.
- 영어 국제과정이 존재한다고 해서 OPIc이 인정되거나 특정 연구실이 영어만으로 지도한다고 단정할 수 없다.

## 범위 원칙
연구 설계는 원칙적으로 다음 구조로 좁힌다.
- 핵심 방법 1개: 예) 물리 기반 모델과 데이터 기반 보정의 결합
- 적용 시스템 1개: 예) 회전기계 또는 로봇 관절 시스템
- 핵심 출력 1~2개: 예) 동적 응답 예측 오차, 모델 업데이트 정확도
- 검증 데이터 1개 이상: 측정 데이터·공개 데이터·연구실 보유 데이터 중 현실적으로 접근 가능한 것

## 재검토 조건
- 최근 논문에서 해당 방법의 연구 공백이 충분하지 않다고 확인될 때
- 실제 지도교수가 사용자의 관심과 맞는 프로젝트를 지도하지 않을 때
- 실험·데이터 접근이 불가능해 검증이 어려울 때
- 영어 입학 경로 또는 일정이 현실적으로 맞지 않을 때
- 사용자가 연구 스타일이나 진로 우선순위를 변경할 때

## 다음 행동
A/B/C/D 연구 방향별로 최근 논문 2~3편을 읽고, 연구 질문·방법·데이터·검증·한계·확장 가능한 직무를 비교한다. 이후 연구실과 입학 요건을 확인한 뒤 주제 선택을 재검토한다.
