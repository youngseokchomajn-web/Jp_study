# DEC-002 — 연구주제 초기축: 스핀들–베어링–구조물 동역학

- 날짜: 2026-10-12
- 상태: PROVISIONAL
- 대체 대상: 없음

## 질문
일본 기계공학 석사 연구주제의 출발점을 사용자의 기존 실무 경험과 연결하면서, CAE·공작기계 기업 R&D에 유효하도록 어떻게 설정할 것인가?

## 확인된 사용자 배경
- 공작기계 구조진동 CAE
- 스핀들-베어링 시스템
- 기계공학 CAE/시뮬레이션 실무 약 4년

## 고려한 대안
1. 공작기계 구조진동 CAE와 실험 모달 해석의 상관성 개선
2. 스핀들–베어링–구조물 연성 동역학 및 공구 끝단 동특성 예측
3. 이송계 동역학과 위치결정 정밀도
4. 공작기계–로봇의 동적 상호작용

## 잠정 판단
대안 2를 중심축으로 선택한다. 기존 경험인 구조진동 CAE와 스핀들-베어링 시스템을 함께 활용하면서, 동적 강성·FRF·회전속도 의존 특성 등 공작기계 성능과 연결되는 지표로 확장할 수 있기 때문이다.

## 이 판단이 확정이 아닌 이유
- 관련 선행연구와 최근 리뷰를 체계적으로 확인하지 않았다.
- 연구 공백과 논문 수준의 차별성이 아직 확인되지 않았다.
- 지원 대상 연구실의 실험장비, 데이터 접근성, 지도교수 연구주제가 미확인이다.
- 석사 기간에 필요한 모델 복잡도와 실험 검증 범위가 미정이다.

## 범위 제한 원칙
우선 하나의 스핀들 또는 제한된 구조 모델, 핵심 출력 1~2개, 검증 가능한 베어링 모델을 기준으로 설계한다. 열·윤활·전자기·절삭 채터를 한꺼번에 포함하는 과도하게 넓은 주제는 피한다.

## 재검토 조건
다음 중 하나가 확인되면 주제를 다시 비교한다.
- 최신 문헌에서 잠정 주제의 차별성이 약하다는 증거가 확인됨
- 목표 연구실이 다른 주제(예: 가공동역학, 이송계, 로봇 정밀도)에 훨씬 강한 역량을 보유함
- 직접 검증 가능한 데이터·실험 환경이 없어 실행이 어렵다고 판단됨
- 사용자가 연구 관심 우선순위를 변경함

문헌 검토 → 연구실 매칭 → 검증 데이터/장비 확인 → 연구 질문 1개와 방법론 1개로 압축.
