# 미결 판단 목록

결론을 미룬 이유와 재검토 조건을 보존하는 목록이다. 미결 상태 자체도 유효한 결과다.

## 해결 규칙
미결 항목을 해결할 때 상태를 갱신하고 증거 URL·확인일·결론을 기록한다. 새 근거가 기존 판단과 충돌하면 이전 판단을 삭제하지 말고 새 DEC 또는 세션 로그에서 변경 이유를 설명한다.


## 2026-10-12 문헌 검토 후 갱신

- OPEN-010: 핵심 논문을 통해 스핀들 동역학 모델·실험 검증 및 물리 모델 기반 상태진단의 연구 사례를 확인함. 연구 공백과 차별성은 추가 검토 필요. 상태: OPEN.
- OPEN-011: 논문에서 실험장치/검증 방식은 확인했으나, 지원 연구실의 장비·데이터 접근성은 확인되지 않음. 상태: OPEN.
- OPEN-013: 물리 모델 + 데이터 보정 후보 질문을 구체화했으나, 연구 공백 및 데이터 접근성은 미확인. 상태: OPEN.
- OPEN-014: 히로시마대 Ibaraki 연구실에서 공작기계 오차 측정·보정과 로봇 오차 연구의 접점을 확인함. 로봇 동역학·제어 프로젝트의 실제 지도 범위는 미확인. 상태: OPEN.
- OPEN-015: NITech 2027년 외국인 사비유학생 모집요강 및 지도교수 목록, Hiroshima University의 석사 입학 안내를 확인함. 2028년 전형, 영어 지도 가능 여부, 실제 지도 수락은 미확인. 상태: OPEN.
- OPEN-016: 확인한 NITech 2027년 전형은 TOEFL iBT 또는 TOEIC L&R을 명시하며, Hiroshima University 일부 전형도 지정된 영어시험을 요구함. OPIc만으로 지원 가능한 후보는 아직 확인되지 않음. 상태: OPEN.
