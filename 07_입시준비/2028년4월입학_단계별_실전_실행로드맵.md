# 2028년 4월 입학 — 실행 로드맵

상세 기준: [운영 마스터플랜](../00_운영/2026-11-01_2028년4월입학_단계별_실전실행계획서.md)

## 지금부터 먼저 할 일 (2026년 11월)
- [ ] 성적증명서·졸업증명서에서 학력과 GPA 원문 확인
- [ ] 재직/경력증명서로 직급과 재직기간 확인
- [ ] 실제 CAE 업무를 개인 기여도 기준으로 2~3개 프로젝트로 분해
- [ ] 회사 기밀 검토 후 외부 공개 가능한 증거만 추림
- [ ] CV의 미검증 GPA, WES 환산, 직급, RPM, 오차율, 개선율, 장비, 수상, 자격, 실험 경력 삭제
- [ ] 실제 사용 툴·분석법만 기술하고 숙련도를 본인이 확인
- [ ] 연구계획서의 연구 질문을 1~2개로 좁힘

## 2026년 12월~2027년 2월 — 후보 검증
- [ ] 19개 후보를 영어 석사과정 / 전공 / 연구실 연결 단위로 조사
- [ ] 2028년 4월 공식 요강과 과거 입학 패턴 구분
- [ ] 연구실 최근 논문을 읽고 본인 경험과 연결
- [ ] 6~8개 후보군과 3~5개 집중 후보 도출
- [ ] 교수 수용 여부는 별도 OPEN/UNKNOWN으로 관리

## 2027년 3월~6월 — 서류·컨택
- [ ] 증거 확인 CV 확정
- [ ] 실제 프로젝트 기반 4~6페이지 포트폴리오 완성
- [ ] 연구실별 연구계획서 변형본 작성
- [ ] 공식 컨택 정책 확인 후 교수 이메일 발송
- [ ] 추천인 후보와 추천 가능 여부 협의
- [ ] 학교별 공식 영어시험 요건·유효기간 확인 (시험 공부는 개인 계획으로 관리)

## 2027년 7월~10월 — 요강·지원
- [ ] 2028 공식 모집요강을 학교별로 확보
- [ ] 자격·일정·서류·시험·영어 점수·추천서·재정증명 확인
- [ ] 예상 일정을 확정 일정으로 쓰지 않음
- [ ] 제출본·접수 확인·결제 내역 보관

## 2027년 10월~2028년 2월 — 전형
- [ ] 학교별 공식 시험 형식에 맞춘 전공 구술/면접 준비
- [ ] CV·포트폴리오·연구계획서 내용의 물리적 근거 설명
- [ ] 결과와 추가 요청 추적

## 2028년 1월~4월 — 입학·출국
- [ ] 지도교수·연구실·등록금·장학금·졸업요건 확인
- [ ] 학교 국제처 안내에 따라 COE·비자·주거·보험 준비
- [ ] 한국 복귀를 고려한 연구성과·진로 계획 정리

## 매월 말 점검
새로 확인된 사실 / 바뀐 판단 / 미결 질문 / 다음 달 산출물을 한 페이지로 기록한다. 문서 수나 조사 횟수를 진척도로 보지 않는다.
