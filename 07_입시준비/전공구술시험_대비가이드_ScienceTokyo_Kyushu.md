# 기계공학 석사 전공 구술·면접 준비 가이드

**대상:** Science Tokyo, Kyushu, Hiroshima 등 후보 프로그램  
**주의:** 이 문서는 기계공학 기초 개념 학습용이다. 학교별 시험 과목·시간·발표 형식·면접 방식이 실제로 동일하다는 뜻이 아니다. 해당 연도 공식 모집요강과 수험 안내를 우선한다.

## 1. 준비 원칙
- 공식을 외우는 것보다 가정, 자유물체도, 경계조건, 단위, 물리적 의미를 설명한다.
- 지원서류에 적힌 모든 기술 주장을 구두로 방어할 수 있어야 한다.
- 실제로 하지 않은 실험·모델링·프로젝트를 수행한 것처럼 답하지 않는다.
- 모르는 질문에는 아는 범위, 추가로 필요한 가정, 검증 방법을 분리해 답한다.

## 2. 기계진동·구조동역학
기본 1자유도계:
\[
m\ddot{x}+c\dot{x}+kx=f(t)
\]
고유진동수(무감쇠):
\[
\omega_n=\sqrt{k/m},\qquad f_n=\omega_n/(2\pi)
\]
감쇠비:
\[
\zeta=c/(2\sqrt{km})
\]
질문 예시:
- 질량·강성·감쇠가 고유진동수와 공진응답에 미치는 영향은?
- 공진 부근에서 위상은 어떻게 변하는가?
- 모드 중첩과 모드 분리는 무엇을 의미하는가?

## 3. FRF와 감쇠 추정
FRF는 입력과 출력 사이의 복소수 주파수응답이다. 예를 들어 변위/힘 receptance는
\[
H(\omega)=X(\omega)/F(\omega)
\]
이며 실수부와 허수부는 복소 응답의 서로 직교하는 성분이다. **허수부 자체가 감쇠량은 아니다.** 감쇠는 적절한 동역학 모델을 이용한 곡선맞춤, 모달 파라미터 추정 또는 전제조건이 맞는 근사법으로 추정한다.

반전력 대역폭법은 충분히 분리된 단일 공진모드, 낮은 감쇠 등 적용 가정에 민감하다. 인접 모드가 겹치거나 응답이 강하게 결합된 경우에는 단순 적용을 피하고 적절한 다자유도 곡선맞춤을 고려한다.

## 4. 회전축·베어링 동역학
설명할 항목:
- 회전축의 질량·강성·감쇠와 자이로스코픽 항
- 베어링의 반경/축방향 지지 특성
- 예압과 접촉각이 접촉하중 및 등가 강성에 미치는 영향
- 회전속도와 온도·원심효과가 운전점에 미치는 영향
- 베어링 지지와 하우징 유연성의 연성

어떤 모델을 사용했는지 말할 때는 입력 데이터의 출처, 가정, 적용 범위와 검증 방법을 함께 설명한다. Jones/Harris 등 특정 모델을 실제 구현했다고 주장하려면 방정식과 코드/계산 절차를 직접 설명할 수 있어야 한다.

## 5. 구조해석과 모델 검증
- 경계조건과 접촉/조인트 모델이 결과에 미치는 영향
- 메쉬 수렴과 요소 선택
- 모드형상 비교 및 MAC의 의미
- FRF의 주파수·크기·위상 비교
- 파라미터 식별가능성과 비유일성
- 검증(verification)과 타당성 확인(validation)의 차이

좋은 상관성은 모델이 현실을 완벽히 재현한다는 증명이 아니다. 측정 불확실성, 모델 오차, 식별된 파라미터의 비유일성을 함께 논의한다.

## 6. 재료역학·선형제어·유체·열역학
후보 학교의 공식 시험 범위가 확인된 뒤 필요한 과목만 우선순위화한다. 공통 기반은 다음과 같다.
- 재료역학: 응력·변형률, 굽힘, 비틀림, 좌굴, 피로의 기본 가정
- 선형제어: 전달함수, 극점·영점, 안정성, 주파수응답, 상태공간
- 유체역학: 연속방정식, 운동량 방정식, 점성, 경계층
- 열역학: 제1·2법칙, 상태량, 에너지수지, 열전달 기본 모드

## 7. 학교별 준비 방식
### Science Tokyo
IGP(C)의 해당 연도 모집요강에서 지원 자격, 평가 방식, 전공 시험 범위, 면접 언어와 제출물을 확인한 뒤에만 과목별 계획을 확정한다. 과거 연도 형식을 2028년에도 동일하다고 가정하지 않는다.

### Kyushu
Global Course의 해당 연도 전형에서 발표자료, 구술시험, 전공 범위, 제출 시점을 확인한다. 발표가 요구되는 경우 연구 관심과 실제 경험을 구분하고, 수치 성과는 증거가 있는 것만 제시한다.

### Hiroshima
해외특별선발 등 정확한 전형명과 해당 연도 시험 형식을 공식 요강으로 확인한다. R-test 또는 특정 장비 경험을 요구하거나 본인이 수행했다고 가정하지 않는다.

## 8. 답변 구조
1. 질문을 한 문장으로 재정의
2. 물리 모델과 가정 제시
3. 지배방정식 또는 핵심 관계 설명
4. 경계조건·입력값·단위 설명
5. 결과의 물리적 의미와 한계 설명
6. 실제 경험인지 이론적 이해인지 명확히 구분

## 9. 개인별 기술 질문 은행
- 베어링 강성 변화가 스핀들 고유진동수와 FRF에 미치는 영향은?
- 베어링 예압과 접촉각은 어떤 방식으로 등가 강성에 반영되는가?
- 하우징 유연성을 무시했을 때 어떤 모드가 잘못 예측될 수 있는가?
- FRF의 크기와 위상은 각각 어떤 정보를 주는가?
- 모델 업데이트에서 여러 파라미터가 같은 응답 변화를 만들면 어떻게 판단할 것인가?
- 실험 데이터가 없을 때 모델의 신뢰성을 어떻게 제한적으로 평가할 것인가?
