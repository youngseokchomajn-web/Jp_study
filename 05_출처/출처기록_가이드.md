# 출처 기록 가이드

각 조사 로그에 핵심 출처를 바로 남기고, 여러 판단에 반복 사용되는 출처는 이 폴더의 별도 문서로 정리한다.

각 출처 항목은 아래 필드를 갖는다.
- ID
- 제목과 URL
- 자료 유형: 모집요강 / 연구실 / 대학 발표 / 기업 발표 / 논문 / 기타
- 발행일과 확인일
- 출처 위치: 페이지, 섹션, 표, 그림, DOI
- 어떤 주장을 뒷받침하는가
- 신뢰 수준: A / B / C
- 한계: 자료가 증명하지 않는 것 포함

특히 논문은 제목·저자·연도·DOI 또는 안정적인 URL을 기록한다. 검색 결과 스니펫만 보고 연구 결과를 확정하지 않는다. 논문을 인용할 때는 초록만 확인했는지, 전문·표·그림까지 확인했는지 구분한다.
