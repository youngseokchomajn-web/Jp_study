# 운영 원칙

## 1. 조사 단위
각 조사에서 네 가지를 분리한다.
1. 사실 확인 — 공식 자료가 실제로 말하는 내용
2. 적합도 평가 — 사용자 연구 관심사와의 연결
3. 입학 현실성 평가 — 전형, 영어 점수, 시험, 일정, 지도교수 수용 가능성
4. 행동 판단 — 연락, 지원 준비, 보류, 제외 중 무엇을 할지

대학과 기업 사이의 산학협력 발표만으로 특정 교수가 프로젝트를 지도하거나 국제 석사생을 받을 수 있다고 단정하지 않는다.

## 2. 출처 우선순위
- A — 1차 공식 자료: 대학원 모집요강, 학과·연구실 공식 페이지, 교수 공식 프로필, 대학·기업 공동연구 발표
- B — 신뢰 가능한 2차 자료: 학회 논문, 연구기관 페이지, 신뢰할 수 있는 보도
- C — 탐색용 자료: 검색 요약, 포럼, 개인 게시물, 오래된 소개 페이지

C 자료는 후보 발견에 쓸 수 있지만 핵심 판단의 단독 근거로 사용하지 않는다. 각 출처에 URL, 확인일, 주장, 출처 위치, 등급, 한계를 기록한다. 지원 일정은 지원 직전에 다시 확인한다.

## 3. 후보 평가 기준
- 연구 적합도: 공작기계, CAE, 동역학·진동, 정밀가공, 로봇, 제어
- 기업 연결성: 목표 기업과의 공식 협력, 연구실 단위 실제 프로젝트, 학생 참여 가능성
- 영어 경로: 영어로 수업·연구지도·논문·학위 취득이 가능한지
- 입학 요건: 전공, 성적, TOEFL/IELTS, GRE, 추천서, 연구계획서, 사전 교수 연락
- 시기: 지원 마감, 시험 준비 시간, 입학 시기
- 현실성: 현재 정보와 준비 상태에서 지원 준비를 진행할 수 있는지

정량 점수는 내부 비교용이지 합격 확률이 아니다. 근거가 부족하면 점수 대신 OPEN으로 둔다.

## 4. 미결 판단 처리
모든 미결 항목에는 아래를 기록한다.
- 무엇을 아직 결정하지 못했는가
- 왜 지금 결정할 수 없는가
- 어떤 증거가 필요한가
- 어디서 또는 누구에게 확인할 것인가
- 어떤 조건에서 다시 검토할 것인가
- 다음 확인 날짜 또는 트리거

미결 항목을 조용히 삭제하지 않는다. 해결되면 상태, 근거, 날짜를 기록한다.

## 5. 판단 변경
중요 판단은 02_판단/DEC-NNN_주제.md 형식으로 기록한다. 필수 항목은 날짜·상태, 질문과 맥락, 근거, 고려한 대안, 선택과 이유, 수용한 위험, 미결 사항, 재검토 조건, 관련 출처 및 이전·후속 판단이다.

이전 판단을 지우지 않는다. 대체되면 이전 기록을 SUPERSEDED로 표시하고 새 판단에서 대체 이유를 설명한다.

## 6. 세션 종료
조사 세션마다 01_로그/YYYY-MM-DD_주제.md 파일에 다음을 남긴다.
- 이번 세션의 질문
- 새로 확인된 사실
- 변경된 판단
- 새로 생긴 미결 항목
- 결론을 내리지 않은 것과 보류 이유
- 다음 행동 1~5개
- 참고 출처

## 7. 파일 구조
- 00_운영/: 운영 규칙과 공통 정의
- 01_로그/: 날짜별 조사 세션
- 02_판단/: 중요한 판단과 변경 이력
- 03_후보군/: 대학·연구실 비교표
- 04_미결/: 재검토할 질문과 필요한 증거
- 05_출처/: 핵심 출처 목록 및 검증 기록
- templates/: 반복 기록용 템플릿
