# 2028년 4월 일본 대학원 진학 — 실전 실행계획서

- 기준일: 2026-11-02
- 목표: 2028년 4월 입학을 기본 경로로 준비
- 범위: 도쿄대학교(UTokyo) 제외. Science Tokyo는 별도 대학으로 유지.
- 운영 원칙: 공식 자료와 과거 패턴을 구분하고, 확인되지 않은 지원자 이력·합격선·일정을 사실처럼 쓰지 않는다.
- 이 문서는 실행계획이며 합격 가능성이나 입학을 보장하지 않는다.

## 1. 현재 기준선
지원자에게서 확인된 방향:
- 기계공학 계열 학부 배경.
- 공작기계 구조·진동 CAE 업무 약 4년 (실제 실무 업무 범위 및 실험/계측 관여 여부 확인 후 포지셔닝 결정).
- 업무 관심·경험 영역: 스핀들 및 베어링 시스템, 하우징/헤드 구조의 FRF 영향, 베어링 강성·예압·접촉각 관련 동특성.
- 연구 관심: 구조동역학, 스핀들–베어링–하우징 연성, FRF/동적 컴플라이언스, 모델 보정 및 진동 기반 진단.
- 일본어 초급. 공인 영어 시험 준비는 본인이 직접 진행하되, 인정 시험 및 점수 요건은 학교별 공식 모집요강 기준으로 확인.
- 졸업 후 한국 복귀를 우선 고려.

확인 전까지 문서에 확정 기재하지 않을 항목:
- 학부 학교명·정확한 학위명·졸업일·GPA 및 과목 성적 (공식 성적표 확인 전까지 CV 및 지원서의 GPA는 확정값으로 취급하지 않음)
- 회사명·공식 직급·정확한 재직기간
- 실험 모달 시험, EMA, TMD, 채터 개선 등 구체적인 수행 이력 (실제 실무 업무 범위 및 실험/계측 관여 여부 확인 전까지 '순수 수치해석' 또는 '실험 수행' 어느 한쪽으로도 일방 단정 금지)
- 수치 성과, 장비, 소프트웨어 숙련도, 수상, 자격, 논문
- 추천서 요구 여부 및 제출 부수 (대학·전형별 공식 요강 확인 전까지 '추천인 2명' 등 특정 숫자로 고정 금지)
- TOEFL/IELTS/OPIc 점수 (TOEFL 85~90점 등 특정 점수를 공통 컷오프로 삼지 않으며, OPIc 역시 모든 국립대 일괄 불인정으로 단정하지 않고 모집요강별 공인 인정 시험 목록을 개별 확인)

## 2. 지원 대학 운영 기준
현재 조사 후보는 19개 대학 기준선을 유지한다. 우선 심층 조사 9개:
Tohoku, Science Tokyo, TUAT, Toyohashi, Nagoya, NITech, Kyushu, Hiroshima, JAIST.
확장 후보 10개:
Hokkaido, Kyoto, Osaka, Tsukuba, Tokyo Metropolitan, Yokohama National, Chiba, Kobe, Shizuoka, Niigata.

이 목록은 조사 대상이지 최종 지원 순위가 아니다. UTokyo는 활성 후보에서 제외한다. 각 대학에 대해 아래 항목을 별도로 판정한다.
1. 영어로 정규 석사학위를 마칠 수 있는 공식 프로그램인가?
2. 해당 전공/연구실이 그 프로그램의 학생을 실제로 지도할 수 있는가?
3. 목표 입학 시기(2028년 4월)가 공식 모집요강에 명시되어 있는가?
4. 해당 연구실이 석사생을 모집·수용할 가능성이 확인되었는가?
5. 교수의 지도 언어, 시험, 서류, 추천서 요구 여부 및 제출 부수, 재정·비자 조건이 공식 자료로 확인되었는가?

상태값:
- CONFIRMED: 2028년 공식 모집요강으로 확인
- HISTORICAL_PATTERN: 과거 동일 시기 운영만 확인
- CONDITIONAL: 프로그램/연구실 연결 등 추가 확인 필요
- UNKNOWN: 근거 부족 또는 미확인
- NOT_AVAILABLE: 해당 경로에서 미운영 확인

연구실 적합도와 학생 수용 여부를 혼합하지 않는다. 교수의 미응답만으로 수용 불가를 판정하지 않는다.

## 3. 실행 단계

### Phase 0 — 신뢰 가능한 지원자 자료 만들기 (2026년 11월)
- [ ] 공식 성적증명서·졸업증명서로 학력 정보 확인
- [ ] 재직증명서/경력증명서로 회사·직급·기간 확인
- [ ] 실제 수행 업무를 프로젝트 단위로 분해하고 개인 기여도 기록
- [ ] 회사 기밀과 공개 가능 범위를 확인
- [ ] CV의 미확인 수치·수상·자격·실험·장비 주장을 제거
- [ ] 실제 프로젝트 2건의 익명화 증거자료 확보 가능성 판단
**완료 기준:** 모든 CV 문장이 증빙 또는 본인 확인으로 설명 가능하고, 미확인 항목은 제거되어 있음.

### Phase 1 — 연구 적합성 및 후보군 압축 (2026년 12월~2027년 2월)
- [ ] 19개 후보의 공식 영어 석사 경로를 프로그램 단위로 재확인
- [ ] 2028년 4월 모집요강 공개 여부와 과거 패턴을 분리 기록
- [ ] 연구실 최근 논문 2~3편을 읽고 실제 연구 방법과 연결
- [ ] 교수 지도 언어, 해당 프로그램 참여, 석사생 모집 여부를 각각 확인
- [ ] 1차 후보 6~8개, 집중 컨택 후보 3~5개로 좁히되 근거를 기록
- [ ] 연구계획서 초안을 각 연구실의 실제 연구와 맞춰 수정
**완료 기준:** 후보별 프로그램-연구실-입학시기 연결표와 미결 질문이 있음.

### Phase 2 — 지원서류 및 교수 컨택 준비 (2027년 상반기, 학교별 일정 연동)
- [ ] CV와 포트폴리오를 증거 감사 완료본으로 정리
- [ ] 실제 실무 업무 범위 및 실험/계측 관여 여부 확인 후 포지셔닝 결정 (순수 수치해석으로 일방 단정하지 않음)
- [ ] 연구계획서 1개 기본본과 연구실별 변형본 작성
- [ ] 교수별 최근 논문에 기반한 맞춤형 이메일 작성
- [ ] 전형별 사전 내락 필수 여부 및 적정 컨택 시점 개별 확인 (2027년 4월 등 특정 시점에 일괄 고정하지 않음)
- [ ] 학교·전형별 추천서 요구 여부 및 제출 부수 개별 확인 후 추천인 후보와 요청 가능 여부를 본인이 직접 협의 (추천인 2명 공통 고정 배제)
- [ ] 공인 영어 성적은 학교·프로그램별 공식 인정 시험(TOEFL/IELTS 등), 최소점수, 유효기간 확인 (TOEFL 85~90점 공통 컷오프 고정 배제, OPIc 일괄 불인정 단정 금지 및 모집요강별 공인 인정 시험 목록 개별 확인; 학습 계획은 이 문서 범위 밖)
**완료 기준:** 각 후보에 제출 가능한 서류 세트와 컨택 기록이 존재.

### Phase 3 — 모집요강 감사 및 원서 준비 (2027년 7월~10월)
- [ ] 2028 입학 공식 모집요강 원문 확보
- [ ] 자격, 일정, 온라인/우편 제출, 시험, 면접, 공인 영어 인정 시험 및 유효기간, 추천서 요구 여부 및 부수, 수수료, 재정증명 확인
- [ ] 과거 일정으로 역산한 예상일을 공식 일정처럼 사용하지 않기
- [ ] 각 대학별 서류 체크리스트와 제출 책임자 지정
- [ ] 번역·공증·성적표 발급 소요시간 확인
**완료 기준:** 학교별 공식 요강을 기준으로 지원 여부와 제출 일정 확정.

### Phase 4 — 제출 및 전형 대응 (2027년 10월~2028년 2월, 학교별 변동)
- [ ] 공식 접수창이 열린 대학에만 제출
- [ ] 제출본·접수 확인·결제 증빙 보관
- [ ] 필기/구술/면접 형식은 해당 연도 공식 안내로 확인
- [ ] 연구계획과 CV의 모든 문장을 구두로 설명하는 연습
- [ ] 합격/불합격/대기 및 추가서류 요청을 기록
**완료 기준:** 지원별 결과와 후속조치가 추적 가능.

### Phase 5 — 입학 결정 및 출국 준비 (2028년 1월~4월)
- [ ] 합격 조건, 지도교수, 연구실, 등록금·장학금, 졸업요건 비교
- [ ] 입학 의사결정 전 재정·주거·보험·생활비 계획 확인
- [ ] COE, 비자, 입국, 기숙사, 등록 절차는 학교 국제처의 최신 안내에 따름
- [ ] 한국 복귀 경로를 고려해 연구성과·기술·산업 연계 계획 수립
**완료 기준:** 공식 입학 허가와 학교 안내에 따른 출국·등록 준비 완료.

## 4. 월별 운영 리듬
매월 말 다음 네 항목만 갱신한다.
1. 새로 확인된 공식 사실
2. 변경된 후보 판단과 근거
3. 해결되지 않은 질문과 담당자
4. 다음 달 완료할 수 있는 산출물

지원서류는 증거가 생겼을 때만 갱신한다. 조사량이나 문서 페이지 수를 성과로 간주하지 않는다.

## 5. 리스크 및 분기
- **2028년 4월 영어 석사 경로가 없는 후보:** 10월 입학이 공식 운영되는지 별도 확인하고, 2028년 10월 대안으로 분리.
- **교수 수용 여부 불명:** 공식 입시 담당자 또는 연구실에 질문. 미응답만으로 탈락 처리하지 않음.
- **실험 시설/데이터 부족:** 실제 실무 업무 범위 및 실험/계측 관여 여부 확인 후 포지셔닝을 결정하되, 실험 시설이나 데이터 접근이 제한적인 경우 수치모델·민감도·식별가능성 중심으로 석사 연구 범위를 현실화.
- **서류 증거 부족:** 해당 경력·성과를 CV에서 삭제하거나 일반적인 업무 설명으로 낮춤.
- **지원 일정 미공개:** UNKNOWN으로 유지하고 공식 발표 시 갱신.
- **영어 성적 요건 미충족:** 학교·프로그램별 공식 인정 시험, 최소점수, 유효기간을 모집요강별로 개별 확인하여 평가 (TOEFL 85~90점 고정 기준 배제, OPIc을 일괄 불인정으로 단정하지 않고 각 모집요강 인정 시험 목록을 대조 확인).

## 6. 저장소 운영과 검수
- 기존 조사 원본은 보존하고 검증본을 별도 관리한다.
- 각 입시 주장에 출처 URL, 확인일, 문서명/항목, 상태를 붙인다.
- 링크 검사, CSV 파싱, 문서 내 숫자·성과 주장 검사를 수행한다.
- Gemini는 조사·초안 작성에 활용하되, 공식 자료와 원문을 직접 대조한 뒤에만 기준 매트릭스에 반영한다.
- CV/포트폴리오 확인이 끝나기 전에는 교수 이메일을 발송하지 않는다.
