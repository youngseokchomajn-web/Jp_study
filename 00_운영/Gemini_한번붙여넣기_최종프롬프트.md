1. 데스크톱에서 https://gemini.google.com/ 을 연다.
2. 입력 도구에서 **Deep Research**를 선택한다.

5. 결과가 나오면 **Export to Docs** 또는 **Copy Contents**로 원문을 보존하고, CSV/Markdown 파일 생성 기능이 가능하면 함께 생성한다.
6. 결과를 이 저장소에 자동으로 푸시했다고 간주하지 않는다. Gemini가 실제 GitHub 쓰기 권한과 작업을 확인하지 못했다면 파일을 내보내고 별도 검증 후 반영한다.

### 2. 지원자 프로필과 목표
- 기계공학 계열 학부, GPA 약 3.5–3.99/4.5
- 기계·공작기계 분야 CAE/시뮬레이션 실무 약 4년
- 경험: 공작기계, 스핀들-베어링 시스템, 구조진동
- 관심 연구:
  A. 물리 기반 모델 + 데이터 기반 보정, 파라미터 식별, reduced-order model
  B. 로봇 동역학·제어
  C. 공작기계 동역학·CAE·정밀기계
  D. 진동 기반 상태감시·고장 예측
- 일본어 초급 이하. 영어로 정규 석사학위를 완료할 수 있는 경로가 필수다.
- OPIc 보유, TOEFL 준비 예정. OPIc가 TOEFL/IELTS를 대체한다고 가정하지 말 것.
- 도쿄권을 선호하지만 연구 적합성이 높으면 일본 전국을 비교한다.
- 졸업 후 한국 복귀를 선호한다.
- 학비·입학금·생활비·장학금은 조사해서 별도 참고 항목에 기록하되, 대학 순위나 제외 기준으로 사용하지 않는다.
- 목표는 대학의 명성 순위가 아니라, 영어 독립 석사 경로 + 실제 참여 연구실 + 지도 가능성 + 검증된 연구 적합성 + 실행 가능한 입시 일정의 조합을 찾는 것이다.

### 4. 네 가지 평가축을 절대 합산하지 말 것
**A — 영어 독립 석사 경로**
- 정규 독립 석사인지 석박사 통합인지, 정확한 학위명, 표준 수학기간
- 강의·연구지도·논문 작성 언어를 각각 구분
- 영어 홈페이지/영어 지원/일부 영어 수업/영어 논문/영어 독립 석사 완료를 서로 다른 개념으로 처리
- 해당 전공이 실제 프로그램에 참여하는지 공식 자료로 확인
- TOEFL/IELTS/GRE, 학위·성적 요건, 시험/면접 방식, 지원 국가·해외 지원 가능성
- OPIc 대체 인정은 공식 명시가 있을 때만 인정

**B — 실제 연구실 연결**
- 공식 연구실명, 교수명, 연구실 페이지, 관련 최근 논문
- 해당 연구실이 해당 영어 석사 프로그램에 참여하는지
- 독립 석사생을 받는지, 해당 입학 회차의 모집 제한이 있는지
- 영어 지도 가능 여부와 사전 지도교수 동의 필요 여부
- 수용 불가 교수 목록, 모집 연구실 목록, 정원 제한, 프로그램별 참가 명단을 확인
- 연구주제가 맞는다는 이유만으로 영어 프로그램 참여나 석사생 수용을 추정하지 말 것

**C — 논문 근거 품질**
- 2022–2026년 논문을 우선하되, 핵심 기반 논문은 이전 연도도 허용
- 제목·저자·연도·학회/저널·DOI·공식 원문 URL
- 연구질문(RQ), 방법·모델·알고리즘, 데이터 출처와 규모, 실험장치·센서·조건
- 검증: 수치 시뮬레이션/벤치 실험/실제 장비/현장 데이터/외부 데이터
- 정량 결과는 본문에 실제로 적힌 수치만 기록
- baseline 비교, ablation, 반복성, 불확도, 외부 검증, 재현성, 저자가 밝힌 한계
- E1=서지정보, E2=공식 초록, E3=본문 방법·데이터·검증, E4=한계·재현성·외부 검증 검토
- E1/E2만으로 성능 우수성·현장 적용 가능성을 단정하지 말 것
- 합성 데이터와 실제 장비/현장 데이터 검증을 명확히 구분

**D — 지원 실행성**
- 2027년 입학(4월/10월 등) 실제 지원 가능 여부와 2028년 대안
- 각 단계별 정확한 마감: 교수 컨택, 사전 매칭, 온라인 신청, 서류 도착, 시험/면접, 결과 발표
- 추천서 수, 연구계획서, 논문/졸업논문 요약, 성적표·학위증명, 시험료
- 장학금 선발과 대학원 입학 심사를 분리
- 연 1회 지원 제한 등 개인별 전형 제약이 있으면 표시
- 공고되지 않은 미래 일정은 이전 연도 날짜를 확정값으로 쓰지 말고 NOT ANNOUNCED/REFERENCE ONLY로 기록

### 5. 근거 규칙
1. 공식 대학·대학원·프로그램·연구실·교수·논문 원문을 우선한다. 검색 결과 스니펫만으로 핵심 결론을 내리지 않는다.
2. 모든 핵심 주장에 직접 뒷받침하는 원문 URL, 문서/페이지 제목, 해당 페이지의 항목·표·그림·문구, 확인 날짜를 붙인다.
3. 공식 자료가 서로 충돌하면 양쪽 링크와 게시/개정 날짜를 기록하고 해결되지 않으면 OPEN으로 둔다.
4. “확인됨 / 근거 일부 있음 / 추정 / 미확인 / 마감 종료”를 구분한다.
5. 지원 자격과 연구실 수용을 모르면 합격 가능성을 숫자로 만들어내지 않는다.
6. 자료가 부족한 대학을 자동 탈락시키지 않는다.
7. 프로그램별 경로가 섞이지 않도록 한다. 특히 Science Tokyo IGP(C) vs IGP(A)/IPSSS, Kyushu Mechanical Engineering Global Course vs IGSES, Hokkaido e3 일반전형 vs MEXT 장학 경로를 구분한다.
8. 현 시점은 2026-10-13으로 취급하고, 일정은 조사 시점의 공식 공고로 갱신한다.

### 6. 조사 순서 — 한 번의 실행 안에서 전 범위를 처리
- 1단계: 18개 대학을 모두 나열한 A/D 입시·영어 석사 매트릭스를 먼저 완성한다.
- 2단계: 모든 학교에서 최소 1개 이상의 관련 연구실을 찾고, 직접 적합 후보가 부족하면 “미발굴”이라고 명시한다. 가능하면 학교당 2개 후보까지 조사한다.
- 3단계: 영어 프로그램과 연구실 연결이 확인되거나 가능성이 있는 후보를 우선해 최근 논문 2–5편을 조사한다. 핵심 후보는 최소 1편 E3/E4까지 검토한다.
- 4단계: 반대 검토(red-team)를 수행한다. 잘못된 영어 경로, 석박 통합 오인, 오래된 마감, OPIc 대체 오인, 프로그램-연구실 연결 오류, 모집 불가 교수, 합성 데이터의 과장, 끊어진 URL을 찾아라.
- 5단계: 확인된 사실·추정·미확인·상충 근거·다음 조치를 통합하고 2027/2028 일정표를 만든다.
- 6단계: 최종 결과가 18개 대학 모두를 다루는지 자체 점검하고, 누락 대학은 결과에 반드시 포함해 OPEN으로라도 남긴다.

### 7. 결과 파일을 이 구조로 만들어라
다운로드/복사 가능한 파일을 생성하라. 가능하면 Markdown과 CSV를 모두 제공하고, CSV는 UTF-8 및 표준 CSV escaping을 사용한다.

- `00_Executive_Summary.md`: 핵심 발견, 즉시 행동, 주요 리스크, 확실하지 않은 사항
- `matrix_admissions.csv`: 학교, 프로그램, 학위 유형, 영어 조건, 입시 요건, 2027/2028 마감, A/D 상태, 근거 URL, 확인일
- `matrix_labs.csv`: 학교, 프로그램, 연구실, 교수, 주제 적합성, 프로그램 연결, 영어 지도, 석사 수용 여부, B 상태, 근거 URL
- `papers_evidence.csv`: 학교, 연구실, 논문, DOI/URL, RQ, 방법, 데이터, 검증 유형, 수치 결과, 한계, E 수준
- `open_questions.csv`: 미확인 사항, 중요도, 필요한 증거, 공식 문의처, 문의 초안, 마감 영향
- `01_영어석사_입시_통합.md`
- `02_연구실_매핑.md`
- `03_논문_근거.md`
- `04_레드팀_검증.md`
- `sources.md`: 출처 인덱스, 근거 위치, 확인일, 직접 뒷받침하는 주장
- `README_조사결과.md`: 위 파일을 읽는 순서와 요약

각 CSV에는 대학당 한 행만 넣어서 서로 다른 프로그램/연구실 정보를 합치지 말고, 반복 행을 허용하라. 파일 생성 기능이 불가능하면 결과를 파일별로 분리된 코드블록/표로 출력하되, 생략부호로 내용을 대신하지 말라.

### 9. 최종 감사 체크리스트
- 18개 대학 모두 포함했는가?

- 2027 일정이 공식 원문과 날짜 단위로 확인되었는가?

- 논문 데이터·실험·검증이 실제 본문에 근거하는가?
- E1/E2만으로 성능을 과장하지 않았는가?
